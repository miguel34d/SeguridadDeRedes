Repositorio con los laboratorios prácticos de la asignatura **Seguridad de Redes**, impartida por el profesor **Jonathan Rondón**. Cada carpeta corresponde a un laboratorio o práctica, con su configuración, documentación y evidencia de funcionamiento.

---

## 📂 Contenido del repositorio

| Carpeta | Descripción |
|---|---|
| [`RDP + IIS`](./RDP%20+%20IIS) | Configuración de RDP RemoteApp, RemoteApp Web Client y página personalizada de IIS sobre Windows Server, con evidencia de funcionamiento desde el cliente |
| [`VPN`](./VPN) | Laboratorio de red con VPN site-to-site (IPsec + GRE), AAA/RADIUS vía NPS, y configuración completa de routers y switches en GNS3 |
| [`Zabbix/Read`](./Zabbix) | Monitoreo de red con SNMP y Zabbix sobre una topología de red plana |

---

## 🛠️ Entorno de trabajo

- **Simulador:** GNS3 / EVE-NG
- **Dispositivos:** Cisco IOS (routers y switches), Windows Server 2022, Windows 10
- **Dominio de laboratorio:** `miguel.local`
- **Documentación:** Markdown (GitHub) y Word en formato APA
